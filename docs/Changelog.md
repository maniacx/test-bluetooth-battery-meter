# Changelogs

{: .important-title }
> Version 0.1.2 &emsp;&emsp; Apr 19, 2026
> * Bumped runtime to GNOME 50
> * Aligned with Flathub submission guidelines
> * Removed pactl and integrated GVC (libgnome-volume-control) for PulseAudio communication, enabling A2DP detection and volume control during conversation mode
> * Removed real-time logging; added optional socket packet logging (disabled by default)
> * Added D-Bus service mode to allow integration with GNOME Shell extension, Plasma widget, and Cinnamon applet
> * Made UI adaptable for mobile layouts
> * Added support for Nothing / CMF Buds
> * Added support for Samsung Galaxy Buds
