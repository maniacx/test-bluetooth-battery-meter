## Application Settings

<br>
<img src="{{ 'assets/images/preferences/application-settings/preferences.png' | relative_url }}" width="55%">

### Realtime log

Clicking this menu opens a real-time log window showing socket traffic, useful for packet analysis and debugging.

<img src="{{ 'assets/images/preferences/application-settings/realtime-logs.png' | relative_url }}" width="100%">

### Dark Mode

<img src="{{ 'assets/images/preferences/application-settings/dark-menu.png' | relative_url }}" width="75%">

This setting allows you to override the system appearance mode.

* Clicking it opens a submenu with three options: System Default, Light, and Dark.
* System Default follows the current system light/dark preference.
* Selecting Light or Dark forces the app to use that appearance.
* Switching back to System Default requires restarting the app for the change to take effect.

<img src="{{ 'assets/images/preferences/application-settings/dark.png' | relative_url }}" width="100%">



### Accent Colors:

<img src="{{ 'assets/images/preferences/application-settings/accent-menu.png' | relative_url }}" width="80%">

This setting allows you to override the system accent color.

* Clicking it opens a submenu with available libadwaita accent colors and System Default.
* System Default follows the current system accent color.
* Selecting a specific color forces the app to use that accent color.
* Switching back to System Default requires restarting the app for the change to take effect.

<img src="{{ 'assets/images/preferences/application-settings/accent-device.png' | relative_url }}" width="100%">
